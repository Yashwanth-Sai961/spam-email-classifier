# 🛡️ Spam Email & Phishing Detection System

An AI-powered web application that detects spam emails, analyzes phishing URLs, and generates a risk score using machine learning and heuristic analysis.

## 🚀 Live Demo

🌐 https://spam-email-classifier-mmyuiehhmruzrkd2mcbdhc.streamlit.app/

## ✨ Features

- Spam email detection using Machine Learning
- Phishing URL analysis
- Risk score (0–100)
- Email safety classification
- Interactive Streamlit dashboard
- PDF report generation
- Fast predictions using trained ML models
- URL heuristic analysis for suspicious links
